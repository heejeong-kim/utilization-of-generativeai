Part. 01 ChatGPT: 인공지능과 함께하는 새로운 학습의 여정 요약

Part. 01은 생성형 AI와 거대 언어 모델(LLM)의 기본 개념부터 ChatGPT의 가입·화면 구성·요금제·맞춤 설정, 그리고 GPT 모델의 발전사와 미래 전망까지를 다룸. ChatGPT를 처음 접하는 학습자가 도구를 이해하고 자신에게 맞게 설정해 활용할 수 있도록 구성함

1. 생성형 AI와 거대 언어 모델(LLM)

생성형 AI(Generative AI)는 기존 데이터를 학습해 텍스트·이미지·음악·비디오 등 새로운 콘텐츠를 만들어내는 인공지능 기술임. 주요 특징은 콘텐츠 생성, 창의성, 폭넓은 응용 분야임

거대 언어 모델(LLM: Large Language Model)은 자연어 처리(NLP) 분야에서 활용되는 특별한 유형의 생성형 AI임. 방대한 텍스트 데이터를 학습해 언어의 문맥을 이해하고 의미 있는 응답을 생성함. 주요 특징은 언어 이해, 대화 생성, 지식 기반임

즉 생성형 AI는 다양한 형태의 콘텐츠를 생산하는 기술 전반을 의미하고, LLM은 그중 자연어 처리에 특화된 모델임

2. 다양한 거대 언어 모델 서비스

2015년 설립된 OpenAI가 ChatGPT로 LLM의 대중화를 이끌었으며, 이후 여러 기업과 연구 기관이 고유한 강점을 지닌 서비스를 제공하고 있음

  • 구글 Gemini: 텍스트·이미지·오디오·비디오를 처리하는 멀티모달 모델
  • 메타 LLaMA: 연구·개발 목적으로 자유롭게 사용 가능한 오픈 소스 모델
  • 앤트로픽 Claude: 윤리적이고 안전한 AI 개발을 목표로 함
  • 중국 DeepSeek: 코딩 및 수학적 추론에 특화
  • xAI Grok: 소셜 미디어 데이터 기반 실시간 정보 분석에 강점
  • 네이버 CLOVA-X: 한국어 데이터에 특화
  • 뤼튼(wrtn): 한국어 기반 콘텐츠 생성에 특화

3. ChatGPT 첫 만남과 회원가입

https://chatgpt.com에 접속하면 '무엇을 도와드릴까요?' 화면이 나타나며, 회원 가입 없이도 질문이 가능함

처음에는 "너는 누구니?", "너는 어떤 일을 할 수 있니?", "정확한 버전은 뭐야?"처럼 ChatGPT 자체에 대해 질문하며 익숙해지는 방식을 권함

회원가입은 이메일 주소 입력 후 비밀번호를 설정하거나, 구글(Google)·마이크로소프트(Microsoft) 계정을 연동하면 더 빠르게 진행할 수 있음. 중간에 이메일 또는 전화번호 인증이 요구될 수 있음

4. ChatGPT 첫 화면 구성

회원가입 후 표시되는 화면의 주요 영역을 다섯 가지로 정리함

  1. 핵심 소통 공간: 중앙 대화(채팅) 창
  2. 활용 가이드: 예시 질문과 기능 소개
  3. 새 채팅과 대화 기록 관리: 좌측 사이드바(사이드바 숨김, 기록 검색, 새 채팅, GPT 탐색)
  4. 정보 공유를 위한 링크 만들기: 공유하기
  5. 사용자 맞춤형 환경 설정: 설정 및 관리 기능

5. 무료 vs. 유료 요금제

개인용 서비스는 무료·Plus·Pro 세 가지로 구분되며, 사용자의 필요와 활용도에 맞춰 선택할 수 있음

  • 무료 요금제(Free Plan): 비용 없이 기본 기능 이용. 3시간마다 16개 메시지로 사용량이 제한되며, 파일 업로드·데이터 분석·웹 검색·이미지 생성 등 고급 기능은 제한적임
  • 플러스 요금제(Plus Plan): 월 $20. 무료 대비 약 5배 많은 메시지, 파일 업로드·데이터 분석·이미지 생성, 맞춤형 GPT 생성 권한 제공
  • 프로 요금제(Pro Plan): 월 $200. 고급 데이터 분석과 우선 기술 지원, 고급 음성·영상 입력, Sora 영상 생성 기능 활용 가능

이 외에 협업과 보안이 강화된 팀 요금제(사용자당 월 $25)와 맞춤형 솔루션인 엔터프라이즈 요금제가 있음. 먼저 무료 버전을 충분히 사용해 본 뒤 필요에 따라 업그레이드하는 방식을 권함

6. 로그인 후 다양한 질문

날씨·미세먼지처럼 검색이 필요한 질문에는 ChatGPT가 웹사이트를 참고해 답변하며, 답변 하단의 '출처'를 누르면 사이트 제목·URL·간략한 설명이 표시됨. 이를 통해 정보의 신뢰성을 판단하고 추가 정보를 얻을 수 있음

'출처' 버튼 아래에는 복사, 좋은 응답, 별로인 응답, 읽어 주기, 캔버스에서 편집, 모델 바꾸기 아이콘이 있음. 좋은 응답과 별로인 응답 피드백은 모델 성능 향상에 활용됨

질문 좌측의 '메시지 편집'을 누르면 질문을 수정해 다시 질문할 수 있고, '현재질문/총질문' 표시와 화살표로 이전·이후 답변을 비교할 수 있음. 우측 상단 '공유하기'의 '링크 만들기' 기능으로 대화를 손쉽게 공유할 수 있음

7. 개인 맞춤 설정: 나만의 AI 비서 만들기

[계정 | ChatGPT 맞춤 설정] 메뉴에서 호칭, 직업이나 역할, 원하는 특성, 추가로 알아야 할 내용을 입력하면 개인 비서처럼 활용할 수 있음

교재에서는 다음과 같은 설정 사례를 제시함

  • 호칭과 직업: '강 교수', '교수'
  • 특성: 단계적으로 생각(Let's think step by step)해 자세히 답변, 맨 앞에 3~4줄 요약 제공, 반말 맺음말 사용, 전문적인 어조, 개조식 3~4단계 구성, 마지막에 추가 질문 예시 제시
  • 추가 정보: 거주 지역, 관심 분야, 답변 활용 목적

맞춤 설정 지침은 저장 후 반드시 '새 채팅'을 열어야 반영됨. 지침이 적용되지 않으면 '새 채팅에 사용'이 체크된 상태에서 '저장'을 누르고 다시 새 채팅을 열어야 함

8. 다양한 분야의 질문 사례

ChatGPT는 특정 분야에 국한되지 않으며, 자기계발·대인관계·일상 등 어떤 주제든 질문이 가능함

교재에서는 대학의 학문 분야와 일반 사회 관심 분야를 통합해 15가지로 정리하고, 각 분야별 초보자용 질문 사례를 3가지씩 제시함. 정치, 경제, 사회, 과학·기술, 문화·예술, 미디어·커뮤니케이션, 건강·의료, 환경·기후변화, 교육·연구, 법학·행정, 인문학·철학, 공학, 예술·디자인, 국제·글로벌 이슈, 데이터과학·AI로 구성됨

9. OpenAI 설립과 GPT의 탄생

OpenAI는 2015년 설립된 연구 기관으로, 일론 머스크(Elon Musk), 샘 올트먼(Sam Altman), 리드 호프만(Reid Hoffman) 등이 공동 창립자로 참여함. 인공지능 기술의 민주화와 독점 방지를 초기 목표로 삼았으며, 2019년에는 영리 자회사(OpenAI LP)를 설립해 투자 유치에 나섰음

핵심 기술 용어는 다음과 같이 설명함

  • GPT(Generative Pre-trained Transformer): '생성 사전 훈련 변환기'. 방대한 글을 학습해 문장을 이해하고 다음 단어를 예측하며 자연스러운 글을 생성함
  • 사전 훈련(Pre-training): 인터넷의 수많은 텍스트를 읽으며 단어와 문장의 관계, 문법, 지식을 익히는 과정
  • 미세 조정(Fine-tuning): 특정 분야 데이터를 추가 학습시켜 원하는 결과물을 더 잘 만들도록 하는 맞춤형 과정

10. GPT와 ChatGPT의 발전 과정

GPT 모델은 GPT-1.0(2018년, 1.17억 개 매개변수), GPT-2.0(2019년, 15억 개), GPT-3.0(2020년, 1,750억 개)으로 급격히 발전함

2022년 11월 출시된 ChatGPT 1.0은 GPT-3.5 기반 챗봇으로, 인간 피드백 기반 강화 학습(RLHF: Reinforcement Learning from Human Feedback)을 도입해 대화 성능을 향상시킴

이후 ChatGPT-2.0(2023년, GPT-4 기반), GPT-4o(2024년, 멀티모달 강화), GPT-4o Mini(경량화), o3 계열(추론 능력 강화), GPT-4o 일정 예약 기능(2025년), ChatGPT-4.5(2025년, 할루시네이션 감소)로 이어지며 멀티모달 기능과 추론 능력이 지속적으로 개선됨

11. AI 미래 트렌드

교재에서는 앞으로 예상되는 변화를 다섯 가지로 정리함

  1. AI 언어 모델이 인간 수준의 언어 이해 및 생성 능력에 도달함
  2. 로봇공학과 AI의 융합으로 인간과 유사한 로봇이 가사·간병·서비스 산업에 도입됨
  3. AI 칩 시장의 경쟁 심화로 공급 증가, 가격 하락, 기술 발전이 이어짐
  4. 의료·교육·금융 등에서 혁신이 확산되지만 일자리 구조 변화와 윤리적 문제도 동반함
  5. 투명성·책임성·공정성을 확보하기 위한 윤리적 고려와 규제의 중요성이 커짐

핵심 정리

Part. 01의 핵심은 생성형 AI와 LLM의 개념을 구분해 이해하고, ChatGPT를 실제로 가입·설정·활용해 보며 도구에 익숙해지는 것임

특히 '개인 맞춤 설정'은 ChatGPT를 단순한 정보 검색 도구가 아니라 사용자의 목적과 스타일에 맞춰 답변하는 개인 비서로 만들어 주는 기능임. 또한 GPT 모델의 발전 과정과 AI 미래 트렌드를 함께 이해하면, 도구의 현재 한계와 앞으로의 변화 방향을 균형 있게 바라볼 수 있음
